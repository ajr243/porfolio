# Andrew Russo portfolio

Personal portfolio with golf and travel photography, cursor-following backgrounds, and circular slideshow controls.

## Preview

Open `index.html` in a browser. No installation or build step is required.

## Hosting

GitHub Pages serves the root of the `main` branch:
https://ajr243.github.io/porfolio/

Changes to the published files on `main` trigger a Pages update. Photo, stylesheet, and script paths are relative so the site works under the repository URL.

Local recovery folders and design mockups are excluded from Git.
